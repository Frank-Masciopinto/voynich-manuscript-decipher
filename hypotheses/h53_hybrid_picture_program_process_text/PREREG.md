- **Pictures (Theory A):** one astrological herbal / spa medicine *picture program*

A pass supports the hybrid as a *working description*. It is **not** a reading of any EVA word.

## Tests

### T1 — Picture-order program (A)

- Statistic: Spearman ρ between hypothesized ranks (1..5) and observed mean ordinals of the five roles.
- **Null:** 1000 random permutations of the five hypothesized ranks (equivalently: shuffle which rank attaches to which observed mean).
- One-sided p = fraction of null ρ ≥ observed ρ.
- Also report Kendall τ; and ρ/p for the h52 menstrual order on the same book (recomputed).
- **P1 passes** if primary A has ρ > 0.6 **and** one-sided p < 0.05.
- Expectation stated in advance: **P1 likely passes** (herbal early, baths after zodiac, pharma and stars late); h52 contrast should stay non-significant.

### T2 — Text is process (D)

On the three hands {1A, 2B, 3B}, using **stored** numbers only (no new generator fit):

1. **Word-order gain D1 ≤ 0** on raw MS text per hand (from h49 `raw_D1`, or h47/h20 fingerprint D1 if h49 missing a hand). Pass per hand if D1 ≤ 0. **P2a** needs ≥ 2/3 hands.
2. **De-padded seed D1 still non-positive:** h49 `local_W25_D1` ≤ 0 in ≥ 2/3 hands (S1 style; do not require beating PLC).
3. **Burst / within-folio drift like the copier, not topical Italian:** h48 D1 (edit-lag slope) passes in ≥ 2/3 MS hands **and** the Italian control `it_boccaccio` fails that same D1 (S_edit ≤ 0 or D1_pass false), as already stored.
4. **h47 support:** `page_line_copier` passes ≥ 5/6 benchmarks on ≥ 2/3 hands (from h47 summary).

- **P2 passes** if P2a, (2), (3), and (4) all hold.
- Expectation: **P2 passes** (reuses established D-side results).

### T3 — Split prediction (pictures ≠ words)

If A were carried by the *words*, section identity should predict word bags beyond hand×language and quire. Prior work says it does not.

- **P3a (illustration / quire side):** section labels and illustration codes in `quires.csv` are near-deterministic (each section maps to one illustration letter H/Z/B/P/S/…). Report normalized mutual information or exact match rate section↔illustration; **P3a passes** if match rate ≥ 0.95 (picture program is the section coding).
- **P3b (words die under nulls):** from stored h10/h11: unique section R² given other factors is small, and no section-vs-word contrast survives **both** hand and quire nulls after Holm. Specifically use h10: unique section R² ≤ 0.05 **or** FINDINGS statement that section on hand residuals vanishes once quire is removed. Re-read `variance_decomposition.csv` / summary; do not invent new enrichment lists.
- **P3 passes** if P3a and P3b both hold (pictures track section; words do not beyond hand×quire).
- Expectation: **P3 passes**.

### T4 — Thin residual for A (picture anchors only; no EVA glosses)

- **Allowed picture-side anchors (report only, not new glosses):**
  - h05: zodiac circle-centre month names are later **Roman script**, not Voynichese.
  - h09 image typology: roots/jars on pharmaceutical pages, plants on herbal, baths/nymphs on biological (visual tags / illustration codes).
- **Must stay null on the word side:** h51 L1 and L2 remain failed (label↔seed and same-plant de-padded pairs at chance). Do **not** invent EVA→English maps.
- **P4 passes** if (i) T1/P1 passes (picture order), (ii) h51 L1 and L2 are both false in the stored summary, and (iii) the README states Roman months + jar/root *image* typology as the only A anchors used.
- Expectation: **P4 passes** when P1 passes.

## Verdict rule

- **Hybrid supported:** P1 ∧ P2 ∧ P3 ∧ P4 all pass.
- **Picture-only:** P1 ∧ P4 pass, but P2 or P3 fails.
- **Process-only:** P2 passes, but P1 fails.
- **Unsupported:** anything else.

Also state clearly: this is a **working theory** about picture program + writing process; **not** a translation.
