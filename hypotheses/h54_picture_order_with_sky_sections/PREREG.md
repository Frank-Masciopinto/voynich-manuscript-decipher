# h54: picture order with astronomical and cosmological sections (pre-registration)

Written and committed **before any h54 statistic was computed**. No translation claims.
Do not edit this file after it is committed.

## Question

Does the h53 hybrid *picture program* still hold when **astronomical** and **cosmological**
pages are folded into the order map — i.e. as a mid-book **calendar / sky block** with the
zodiac — and is that order robust under quire-aware / hand-coverage sensitivity?

A pass supports a **revised picture story** (calendar block interleaved with the spa/herbal
handbook). It is **not** a reading of any EVA word.

## Data

- Quire / section / hand / illustration map: `data/quires.csv` via `msdecipher.quires.load_quires`.
- Page ordinal `ord` = 0-based row order in `quires.csv` (same as h52/h53).
- Numpy seed **54**. Permutations / bootstraps: **1000**.
- Contrasts reuse the same ordinal book: h53 five-step order and h52 menstrual role order
  (recomputed here; not re-fit from stored ρ).

## Role map (fixed before computing)

### Primary order A (5 roles; sky_mid merge)

| Role | Definition | Hypothesized rank (1=earliest) |
|---|---|---|
| `herbal` | `section == herbal` | 1 |
| `sky_mid` | `section ∈ {astronomical, cosmological, zodiac}` | 2 |
| `biological` | `section == biological` | 3 |
| `pharmaceutical` | `section == pharmaceutical` | 4 |
| `stars` | `section == stars` | 5 |

**Exact predicted primary order:**

`herbal` < `sky_mid` < `biological` < `pharmaceutical` < `stars`

Rationale (stated in advance): h53 left astronomical (mean ord ≈ 122) and cosmological (≈ 137)
beside the zodiac; the hybrid picture story revises to one mid-book calendar/sky block between
plants and baths, then pharmacy, then late stars. Text-only pages are out of scope for the
order score (same as h53).

Observed rank of a role = **mean** `ord` over pages in that role.

### Sensitivity orders (reported; not required for P1)

- **S1 — seven-role expanded (no merge):**  
  `herbal` < `astronomical` < `cosmological` < `zodiac` < `biological` < `pharmaceutical` < `stars`
- **S2 — early sky only (drop Q14 cosmological):**  
  `sky_mid_early` := astronomical ∪ zodiac ∪ cosmological pages with `quire ∈ {8, 9, 10}`;  
  order `herbal` < `sky_mid_early` < `biological` < `pharmaceutical` < `stars`
- **S3 — h53 five-step contrast** (zodiac alone, no astr/cosmo):  
  `herbal` < `zodiac` < `biological` < `pharmaceutical` < `stars` (same definition as h53 primary)
- **S4 — h52 menstrual contrast** (roles as in h52/h53):  
  `water_blood` (biological) < `moon` (zodiac) < `plants` (herbal ∪ pharmaceutical) < `end_yoga` (Q20 stars)

## Tests

### T1 — Extended picture order

- Statistic: Spearman ρ between hypothesized ranks (1..5) and observed mean ordinals of the
  five primary roles; also Kendall τ.
- **Null:** 1000 random permutations of the five hypothesized ranks onto the observed means
  (shuffle which rank attaches to which observed mean). One-sided p = fraction of null ρ ≥ observed ρ.
- Also report ρ/p for S1, S2, S3 (h53), and S4 (h52) on the same book.
- **P1 passes** if primary A has ρ > 0.6 **and** one-sided p < 0.05.
- Expectation stated in advance: **P1 likely passes** (sky_mid sits between herbal and biological);
  S1 may weaken because cosmological pages straddle zodiac and also sit in Q14 after baths;
  S3 (h53) should still pass; S4 (h52) should stay non-significant.

### T2 — Quire-aware / hand-coverage sensitivity

1. **Quire bootstrap (T2a):** 1000 bootstrap resamples of the *set of quires* (sample quires with
   replacement). For each draw, take the multiset of pages from the drawn quires (a quire drawn
   *k* times contributes its pages *k* times). Recompute role means; if any primary role is
   missing, discard and redraw until 1000 valid draws. Record ρ of primary order each time.
   - **P2a passes** if the **5th percentile** of bootstrap ρ is **> 0.6**.
2. **Leave-one-quire-out (T2b):** for each quire that contains at least one page of a primary
   role, drop that quire’s pages, recompute means (skip if a role vanishes), score ρ.
   - **P2b passes** if **every** evaluable LOQO ρ is **> 0.6**.
3. **Hand coverage (T2c, report-only):** cross-tabulate `lfd_hand` × section for primary roles.
   No single hand is expected to cover the full five-role program (sky/zodiac ≈ hand 4; baths ≈
   hand 2; Q20 stars ≈ hand 3). **P2c does not vote**; document the coverage. Optional: within
   hand 4 only, report mean ords for astronomical / cosmological / zodiac (sky-internal order),
   without a pass/fail bar.

- **P2 passes** if P2a ∧ P2b.
- Expectation: **P2 likely passes** for the merged sky_mid order; LOQO may be tight when
  dropping Q13 (only biological quire) or Q20 (dominates stars).

### T3 — Hybrid picture-story documentation

- Document where mid-book sky pages sit (quires, ord ranges, interleaving with zodiac and with
  early Q8 stars / late Q14 cosmological).
- State whether the hybrid working theory should be **revised** to: plants → **calendar/sky
  block** (astronomical ∪ cosmological ∪ zodiac) → baths → pharmacy → stars — without claiming
  translation.
- **P3 passes** if (i) P1 passes, and (ii) the README states the revised interleaved calendar-block
  story when primary means are strictly increasing in that order; if P1 fails, P3 fails and the
  README states that folding sky sections does *not* support that revision.

## Verdict rule

- **extended_order_supported:** P1 ∧ P2 ∧ P3 (sky-aware picture order holds and is quire-robust;
  hybrid picture story revised as above).
- **order_ok_fragile:** P1 ∧ P3 but not P2 (order fits means but not quire sensitivity).
- **not_supported:** otherwise.

Also state clearly: **not a translation**; process-text side of h53 is assumed unchanged and is
not re-tested here.

## Out of scope

- Inventing EVA glosses; claiming sky pages “mean” planets, yoga, or menstrual creation.
- Re-running h47–h51 text suites.
- Reordering quires or proposing a new physical collation.
